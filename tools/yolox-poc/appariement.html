Une mesure, pas une décision. On calcule la signature de chaque voiture sur la dernière image propre avant et sur la première image propre après, puis toutes les distances entre les deux groupes. Rien ici ne devient un seuil : la marge est affichée pour être lue.

Mémoire multi-observations — une identité n'est pas un crop

Le suivi est rejoué sur le plan qui précède la coupure ; chaque piste range ses observations propres (détection forte, non fusionnée, non ambiguë, hors bord de cadre). On compare ensuite les détections d'après la coupure à ces mémoires, pour toutes les combinaisons d'agrégation, de taille et de descripteur. Rien n'est branché dans le suivi — la mémoire est remplie et lue, jamais utilisée pour associer.
